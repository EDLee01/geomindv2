# Translation & Polishing Skill (Do Agent)

## Purpose
Translate manuscripts between Chinese and English with academic style.

## Translation Mode

### Chinese → English

**Process:**
1. Semantic translation (not word-by-word)
2. Academic expression adjustment
3. Terminology standardization
4. Grammar and style check

**Guidelines:**
- Use active voice where appropriate
- Maintain paragraph structure
- Preserve technical terms correctly
- Avoid overly complex sentences

### English → Chinese

**Process:**
1. Meaning-based translation
2. Chinese academic style adjustment
3. Ensure fluent reading

## Polishing Standards

### Grammar Check
- Subject-verb agreement
- Tense consistency
- Article usage (a/an/the)
- Preposition accuracy

### Academic Style
**Avoid:**
- First person (I, we) unless required by journal
- Colloquial expressions
- Overly long sentences (>30 words)
- Redundant phrases

**Prefer:**
- Passive voice for methods
- Active voice for clear actions
- Precise vocabulary
- Concise expression

### Common Corrections

| Avoid | Use Instead |
|-------|-------------|
| "In order to" | "To" |
| "Due to the fact that" | "Because" |
| "It is worth noting that" | (Remove or rephrase) |
| "A lot of" | "Many" / "Numerous" |
| "Nowadays" | "Currently" / "Recently" |
| "More and more" | "Increasingly" |
